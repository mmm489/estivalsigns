# Revenue Signals

Demostración anonimizada de un calendario corporativo de demanda hotelera.
Los nombres de la cadena, establecimientos, zonas, eventos y competidores son
ficticios y no representan una cartera real.

## Alcance

- Cartera demo de 18 establecimientos: hoteles, apartamentos y campings.
- Jerarquía corporativa por zona, destino, establecimiento y alojamiento.
- Calendario de 18 meses con temperatura de demanda explicable.
- Festivos y vacaciones escolares de mercados emisores.
- Eventos, meteorología y comp set para el destino piloto.
- Agenda, comparador de fechas, pesos configurables y eventos manuales.
- Frontera explícita: no usa ocupación, ADR, reservas, PMS ni datos de huéspedes.

## Fuentes previstas

- Nager.Date y OpenHolidays para calendario público.
- Ticketmaster para eventos, con clave del servidor.
- Open-Meteo para meteorología.
- CSV para el comp set.
- Ulyses reservado para una futura integración agregada y sin PII.

## Presentación

La interfaz se identifica como `Revenue Signals` y muestra un aviso visible de
anonimización. La cartera ficticia mantiene la variedad de costa, ciudad y
montaña para enseñar el funcionamiento sin revelar una empresa concreta.
